**What I care about**

I treat infrastructure cost as an engineering problem. Idle resources get right-sized or removed, and savings come from better design rather than cut corners.

I prefer removing complexity to adding it. Fewer moving parts means fewer failure points, so I value a pull request that simplifies a system as much as one that adds a feature. The goal is simple, predictable systems that don't need anyone's attention at 3 a.m.
